# r72 work log (2026-11-04)

## Changes

1. Converted `gojo_awakened.animation.json` into GeckoLib keyframe schema. All 1,084 keyframes across 16 clips now use `{ "vector": [...] }`; previously Bedrock `{ "post": [...] }` and raw arrays caused resource validation failures.
2. Connected ordinary Hollow Purple to `animation.gojo.purple_cutscene`, matching the 22.975-second Bedrock cutscene clip. The old `purple_normal` clip remains in the resource file.
3. Added block ray tracing to `HollowPurpleEntity`. On block contact it moves to the exact hit point, applies mode-specific impact damage/status, destroys terrain according to mob-griefing rules, emits a layered purple/blue/explosion burst, plays impact sound, and discards the projectile.
4. Updated the Gojo low-health audit to test the current standalone Gojo entity implementation rather than a retired prototype path.
5. Updated native Mahito diagnostics to locate the supplied JujutsuCraft v51 jar first. Corrected renderer bytecode report path in its audit.
